These answers are **built**, not recorded: no Materials Project key was available on 2026-10-16.
Their shape is the API's (the `Response[SummaryDoc]` schema of api.materialsproject.org's OpenAPI,
version 0.87.3: `data`, `errors`, `meta.total_doc`; the `SummaryDoc` fields and their units);
`no-key.json` is the API's real answer to a call without a key (401). The ids, formulas and space
groups name real materials, but **every number is a placeholder** to test the reading, not a value
of the Materials Project: do not quote them.
